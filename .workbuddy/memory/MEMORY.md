# 项目记忆 - 锦欣橘米产康看板

## 项目概述
- 项目：产康看板设计
- 目标：促进在所客户对产康的理解和身体治疗过程对比，链接医生查房记录到产康产品推荐
- 委托方：锦欣橘米月子中心（成都）

## 设计方案核心
- 三层架构：数据输入层 → 智能处理层 → 展示输出层
- 三大模块：妈妈恢复看板、产康产品推荐、医生查房面板
- 核心转化路径：医生查房→症状识别→看板推送→妈妈决策→产康疗程
- 呈现形态：妈妈端Pad/小程序、医生端查房Pad、产康顾问端PC、公共大屏

### 5. 私密首次评估表（Excel）
- 12项诊断分类 + 肌力分型（Ⅰ/Ⅱ型，深度/浅/深）+ POP-Q 8点测量 + A3反射
- 主诉维度：性生活频率/疼痛/快感 + 8项症状清单

## 核心发现
- **医生诊断语言 ≠ 产品名称**：医生写"子宫脱垂""会阴未闭"，但产品叫"盆底肌电刺激""私密射频"，中间需要一层"诊断→产品"的智能翻译
- **评估数据分散在4个表单**：出院信息→母乳/盆底问卷→腹直肌评估→私密评估→康复建议，需要统一客户健康档案视图
- **套餐比单项目更有转化价值**：18个套餐 vs 27个单项目，套餐设计已考虑症状组合（如"安心卡"同时包含子宫复旧+腹直肌+盆底肌）
- **双时间线必需**：大部分客户28-30天出所，也有42天的，"产后第X周"不能准确反映在所进度。产后天数决定医学内容，在所天数决定节奏感
