1. **双时间线架构**：
   - 产后天数（医学恢复时间线）→ 决定内容/科普/参考值
   - 在所天数/总天数（入住进度条）→ 决定出所提醒节奏/进度感

2. **表单区新增**：
   - 「入住日期」+「离所日期」两个日期选择器
   - 自动计算：在所第X天/共Y天、套餐类型识别（28天/30天/42天）
   - 日期提示改为"产后第21天 · 在所第20天 / 共28天"

3. **信件展示变化**：
   - envelope区：产后第X天·第Y周 + 在所第X天/共Y天 双行展示
   - 新增进度条（粉→金渐变填充），显示在所进度%+离所还X天
   - 称呼副标题：从"第N封恢复周报"→"你在橘米的第X天"
   - section-tag：WEEK N · 产后第X天
   - 医生查房标注：产后第X天查房
   - 底部：基于产后第X天评估数据生成

4. **出所提醒卡片**（checkout-reminder）：
   - 触发条件：在所天数 ≥ 总天数-7天时自动出现
   - 离所≤3天："做全面评估+确认出院方案+带训练计划"

5. **情绪确认语**（AFFIRMATIONS）：
   - 从硬绑定6周→改为基于在所进度%（0-20%→20-40%→...→100%）
   - 文案去掉了"产后第X周"的固定表述，改为通用描述

6. **模板数据**：
   - 所有TEMPLATES新增 stayDays/totalStayDays 字段
   - 轻度/常见/会阴/乳腺+盆底 → 28天套餐
